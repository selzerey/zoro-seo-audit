# Reading competitor results for one query

Use before rewriting or creating a page. The goal is a coverage table built from pages you actually read, not a
guess about "what Google wants".

## Steps
1. **Pick the query.** One primary query per page, taken from Search Console (the query with the most impressions
   for that page) or, for a new page, the term users type (Bing/GSC queries of sibling pages, autocomplete).
2. **Open the top 3-5 organic results yourself** (skip ads, forums only if they dominate). If a page does not load or
   is behind a wall, write "not read" for it. Never fill a row from the snippet or from memory.
3. **For each result write down:** format (tool, guide, list, news, forum), the H2 list, date shown, what it has that
   no other result has (its angle), and the concrete facts it gives (numbers, sources, examples).
4. **Build a coverage table:** one row per sub-topic, one column per competitor.
   - in 4+ results → expected; missing it makes the page look incomplete
   - in 2-3 → worth covering if it fits the intent
   - in 1 → that page's angle; copy only if it serves your reader
   - in none, but users ask it (GSC queries, People Also Ask, support mail) → your opportunity
5. **Match the format the results agree on.** If four of five results are calculators, a long essay will not rank for
   that query; if they are guides, a bare tool will not either. Mixed results usually mean two intents: serve the
   main one, link to a page for the other.
6. **Decide what you add that they do not:** your own data, a worked example with real numbers, a primary source,
   a clearer table, a tool. "Longer" is not an advantage.

## Traps
- Scraped or tool-reported SERPs can be poisoned or personalised (see `false-positives.md`). Read in a clean
  browser session and confirm the page's real position in Search Console before acting on a "drop".
- Do not lift headings or wording. Use the table to find gaps, then write in your own structure.
- One read is a snapshot. Note the date; re-read only when GSC shows the page moving.
